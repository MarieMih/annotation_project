# Про то, как запускать

Если первый раз запускаете:

conda env create -f environement.yml
подразумевается, что каналы bioconda и conda-forge уже настроены. Может быть ошибка с pip, на функциональность не влияет, telegram-send не работает сейчас, к сожалению.

Затем настроить базу данных.

python cli.py setting и выбрать бактовскую базу

Для файла доверенных белков, если понадобится.
В базе NCBI Taxonomy найти taxid, который интересен (плюс одна задача встроить поиск в калинку).
python cli.py setting когда спросит про user-proteins, указать нужный.

# Строение проекта

Модули:  

необходимый и пока работающий минимум  

- cli.py (интерфейс и запуск пайплайнов)
- main.py (пайплайны)
- create_protein_trusted_list (скачивание баз для бакты и прочего)
- preparation.py (функции для фильтрации ридов и сборки)
- cohort_annotation.py (все связанное с аннотацией)
- correct_annotation_files.py (модификация tsv файлов отдельных аннотаций)
- pangenome_analysis.py (функции, связанные с построением матриц генов и расчетом пангенома)
- make_common_protein_fasta.py (функции, связанные с кластеризацией. Через этот модуль добавляются любые тулы кластеризации)
- make_common_feature_fasta.py (то же, только для всего некодирующего)
- helpers.py (всякие общие вспомогательные функции типа проверки наличия файлов или текущего времени)
- common_variables.py (переменные, к которым обращаются функции из разных модулей)
- resource_monitor.py (сбор статистики времени и загрузки системы, полностью сгенерирован ИИ и не проверялся внутри по коду, только тестировался)  

в переработке и разработке  

- correcting_gff.py (генерация gff по tsv, надо полностью переписывать под новый вариант)
- gff_functions.py (функции для работы с gff файлами)
- converting_to_gtf.py (конвертация в gtf для совместимости с nf-core/rnaseq, раньше работало, сейчас надо проверять)
- uniprot_api.py (обновление записей по текущему uniprot, раньше делалось через UPIMAPI)
- mass_charge.py (подсчет массы и заряда белка, обсудили, что не нужно)
